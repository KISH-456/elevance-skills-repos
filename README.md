### 1. Multi-Modal AI Assistant

> A multi-modal AI assistant that understands text and images to provide context-aware, evidence-based responses. Features visual analysis, conversational memory, ambiguity handling, and intelligent reasoning using open-source AI models and modern NLP frameworks.

---

### 2. Multilingual AI Chatbot

> An AI chatbot with multilingual support that automatically detects languages, preserves conversation context across language switches, and delivers consistent responses. Built using open-source NLP models with cross-lingual reasoning and context-aware conversations.

---

### 3. Dynamic Knowledge Base Chatbot

> A RAG-based AI chatbot that automatically updates its knowledge base by adding new information to a vector database. Supports continuous knowledge expansion, semantic search, and accurate, context-aware responses using open-source AI frameworks.
